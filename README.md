# Speech · 即兴演讲练习 🎤

> 9 组 444 个词条 + 60 秒演讲计时 + 7 档梗复盘评分

## 🚀 在线使用

👉 **https://zhizhi513.github.io/speech/**

## ✨ 功能

- **9 组词库**（444 条）：人工智能、计算机技术、数据安全、产品、效应定律、管理经济、股票投资、计算机硬件
- **抽题动画** + 准备倒计时 + 60 秒演讲计时
- **复盘记录**：7 档专属梗评分——「夯爆了/夯/顶级/人上人/NPC/拉完了/拉中拉之拉一裤兜」
- **PWA 离线**：添加到主屏幕当 App 用，没网也能用

## 📱 手机使用

### iPhone
1. Safari 打开链接
2. 点底部分享按钮 → 「添加到主屏幕」
3. 主屏幕出现橙色「S」图标，点开即用

### Android
1. Chrome 打开链接
2. 右上角菜单 → 「添加到主屏幕」
3. 主屏幕出现图标

## 📦 本地运行

双击 `index.html` 即可使用（首次需要联网）。

## 🎯 文件说明

- `index.html` - 单文件 App
- `manifest.json` - PWA 配置
- `sw.js` - Service Worker（离线缓存）
- `answers/` - 444 个词条的标准答案
