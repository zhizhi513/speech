# 数据出境

> 标准答案（约 200 字）

数据出境就是数据离开国境——你在国内的服务器把用户数据传到海外的云或者母公司，都算。比如 App 收集国内用户的手机号，存在新加坡 AWS 上，这事儿就触发监管了。中国对数据出境有严格规定：达到一定数量门槛就得申报数据出境评估、签标准合同或做安全认证。为什么要这么严？因为数据是国家的战略资源，里面有国民的隐私、商业的命脉。2017 年《网络安全法》就明确了这事儿，2021 年的《数据安全法》和《个人信息保护法》进一步收紧。它告诉我们：数据流到哪里，安全责任就跟到哪里。今天我想说，全球化做生意容易，数据搬家要合规。
