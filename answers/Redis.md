# Redis

> 标准答案（约 200 字）

Redis 讲的是，一个把数据放在内存里跑的数据库，速度比传统数据库快几十倍，主要用来当"缓存"。它的全名是 Remote Dictionary Server，2009 年由意大利人 Salvatore 开发。Redis 的核心是快——读写都在内存里，几万次一秒轻轻松松。最常见的例子是：你在电商 App 看商品，每次点详情都要查库存，如果每次都查数据库会卡死，先放 Redis 缓存一下秒开；再比如微博热搜榜单，访问量巨大但更新慢，存 Redis 比数据库省心十倍。它给我们的启示是：1. 速度来自内存而非磁盘；2. 缓存用对地方能救命；3. 简单工具解决大问题。今天我想说，快不是技术炫耀，是用户体验的底线。
