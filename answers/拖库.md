# 拖库

> 标准答案（约 200 字）

拖库是黑客把数据库整个拖走——行话里的"拖"就是下载。一般步骤是：先"脱裤"——通过 SQL 注入、弱口令、权限提升等拿到数据库导出权；然后"洗库"——分析数据分类、整理清洗；接着"撞库"——拿账号密码试别的网站。完整链条叫"拖洗撞"。经典案例早年 CSDN 600 万密码泄露、人人网 5000 万账户流出。被拖库的企业轻则用户隐私泄露，重则破产。防范要点：数据库不在公网、密码加盐哈希、敏感字段加密、操作审计告警、最小权限。它告诉我们：数据库是金库，门窗不牢就守不住家。今天我想说，被拖一次，不只是丢数据，是丢信任。
