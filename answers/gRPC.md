# gRPC

> 标准答案（约 200 字）

gRPC 讲的是，一个高性能的远程调用框架，让不同语言写的服务像"本地函数"一样相互通信。它由 Google 在 2015 年开源，基于 HTTP/2 和 Protobuf 协议，比传统的 REST API 更快、更省流量。最常见的例子是：微服务架构里 Java 写的订单服务要调 Go 写的库存服务，用 gRPC 几毫秒搞定；再比如手机 App 和服务器通信，对延迟敏感的游戏、直播几乎都用它。gRPC 的核心是契约先行——先用 Protobuf 定义数据结构，再生成代码，避免联调扯皮。它给我们的启示是：1. 协议比代码重要；2. 跨语言不再是障碍；3. 性能藏在细节里。这告诉我们一个朴素的道理，统一语言才能真正高效协作。今天我想说，技术选型决定团队效率的下限。
