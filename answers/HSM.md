# HSM

> 标准答案（约 200 字）

HSM 是 Hardware Security Module 的缩写，硬件安全模块——专门管密钥的硬件盒子。和 KMS 比，HSM 更硬核：密钥永远不离开这块硬件，连系统管理员都拿不到明文。打个比方，KMS 像保险柜管理员，HSM 像焊死在你家墙里的金库。HSM 干这些事：生成真随机数、加密解密、签名验签、密钥永不导出、旁路攻击防护。金融行业的支付密钥、银行的根证书、电子签名证书都在 HSM 里。中国要求商密产品做认证才能用，HSM 也得过密评。它告诉我们：保护最宝贵的东西，就要用物理隔离这种"笨办法"。今天我想说，硬件安全是软件安全再努力也补不齐的最后一环。
