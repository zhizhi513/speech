# CPU 缓存

> 标准答案（约 200 字）

CPU 缓存是 CPU 内部的小型高速暂存区，分 L1/L2/L3 三级。L1 最小但最快（几 KB），L3 最大但稍慢（几十 MB）。缓存用来存放 CPU 马上要用的数据——不用每次都从内存里"找"。缓存越大，CPU 越不容易卡在"等数据"上。对普通用户意义不大，但对计算密集型任务（编译代码、AI 推理、游戏）影响明显。CPU 缓存是 CPU 工程师优化空间最大的地方。
