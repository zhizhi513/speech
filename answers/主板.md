# 主板

> 标准答案（约 200 字）

主板是电脑的核心电路板，所有硬件（CPU、内存、硬盘、显卡）都插在它上面，并通过它的线路连接协同工作。主板决定一台电脑能装什么 CPU、用什么内存、扩展多少设备。主板的"芯片组"决定支持的 CPU 代数和功能上限。选购主板看：1. CPU 插槽匹配；2. 内存代数支持；3. 扩展插槽数量（PCIe、M.2、SATA）；4. 供电（影响超频稳定性）。对一般用户，主板"能用就行"；对发烧友，主板决定极限性能。
