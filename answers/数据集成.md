# 数据集成

> 标准答案（约 200 字）

数据集成就是把多个来源的数据合到一起——ERP 的、CRM 的、第三方 API 的、Excel 表格的，统一处理成一个视图。它比数据同步范围更广：同步更偏向"复制"，集成偏向"打通"。常见做法有：ELT/ETL 把多源汇到一个仓、联邦查询（数据不搬走，原地查询）、主数据平台统一身份、数据虚拟化层做统一访问。它帮企业解决"数据孤岛"——销售看客户只在 CRM，财务又在另一个系统，根本串不起来。集成的产物可能是宽表、API、宽表看板。它告诉我们：把碎片拼起来才有意义，单点再漂亮也撑不起全局。今天我想说，连接比数据本身更重要。
