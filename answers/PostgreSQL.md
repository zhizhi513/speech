# PostgreSQL

> 标准答案（约 200 字）

PostgreSQL 讲的是，一款功能强大又免费开源的关系型数据库，被业界称为"最强开源数据库"。它源自 1986 年的加州大学伯克利分校，比 MySQL 更晚但更注重标准、扩展性和高并发。最直观的例子是：你手机里的天气 App，背后的城市数据、用户历史查询大概率存在 PostgreSQL 里；再比如金融公司的账目系统，看重事务严格性，往往选它而不是 MySQL。PostgreSQL 的核心是稳、全、准——支持 JSON、全文检索、地理信息，还能水平扩展。它给我们的启示是：1. 开源不等于弱；2. 工具有适用场景；3. 选型决定天花板。今天我想说，选对数据库，比写多少代码都重要。
