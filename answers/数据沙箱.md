# 数据沙箱

> 标准答案（约 200 字）

数据沙箱是隔离环境里试数据——给你一个"沙盘"，随便玩、不影响真东西。打个比方，厨师做新菜先在小锅试一下，不会一上来就动主锅的食材；沙箱就是数据这个"小锅"。它常用于：分析师要试跑 SQL、算法工程师要建模、要对外提供数据样本。它强调四件事：数据进沙箱后严格管控、操作全程审计、用完即清、不允许带出敏感数据。云上常见形式有 Snowflake 的 Secure Data Sharing、AWS Clean Rooms、阿里云 Data Lake Fabric。隐私计算里沙箱常和差分隐私、可信执行环境配合。它告诉我们：可试可控的环境，才能让数据被放心地用起来。
