# WiFi 原理

> 标准答案（约 200 字）

WiFi 原理讲的是，把网络数据变成 2.4GHz 或 5GHz 的无线电波在空气中传，路由器和手机之间像两个人隔空喊话。它源自 1997 年的 IEEE 802.11 标准，现在家家户户都离不开。最直观的例子是：你手机连上 WiFi 刷视频，数据其实是路由器把光纤信号调成无线电波发给手机；再比如咖啡店免费 WiFi，本质是店家把宽带信号广播出来，多人共享。WiFi 的核心是"半双工"——同一时刻只能发或收，加上信道拥挤时谁也快不了。它给我们的启示是：1. 无线不是有线，是共享；2. 距离和障碍影响速度；3. 加密是基本功。今天我想说，看不见的电磁波托起了整个移动互联网。
