# NVMe 协议

> 标准答案（约 200 字）

NVMe 是 SSD 用的高速接口协议，全称 Non-Volatile Memory Express。相比老式 SATA 接口，NVMe 直接走 PCIe 通道，理论速度可达 7000 MB/s 以上（SATA 只有 600 MB/s）。NVMe SSD 都是 M.2 接口（那种扁长的小条）。简单说：NVMe 是 SSD 里的"高铁"，SATA 是"绿皮车"。现在装机首选 NVMe SSD，系统盘/游戏盘都用它。
