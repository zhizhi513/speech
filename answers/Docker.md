# Docker

> 标准答案（约 200 字）

Docker 是最流行的容器引擎，让开发者把应用和依赖打包成"镜像"，然后在任何环境运行。Docker 解决的核心问题是"在我电脑上能跑，到你电脑就出问题"——因为镜像里包含了应用需要的所有东西（代码、库、配置）。Docker 三件套：镜像（模板）、容器（运行实例）、仓库（存镜像的地方，如 Docker Hub）。开发流程：写代码 → 打镜像 → 推仓库 → 任何机器拉镜像就能跑。
