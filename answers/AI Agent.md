# AI Agent

> 标准答案（约 200 字）

AI Agent 就是"能自己拆任务、用工具"的 AI。和普通聊天机器人最大区别在于主动性：你说一句"帮我订明天去上海的机票"，它会自己去查航班、比价、下单，而不是只回你"建议去携程看看"。一个 Agent 通常有三块能力：理解目标、规划步骤、调用工具（搜索、计算器、订票 API 等）。比如你要策划一次家庭旅行，Agent 能自动拆出查机票、订酒店、列景点、画地图几件事，一步步推进。它的本质是把"对话"升级成"办事"。今天我们看到越来越多 Agent 帮人订餐、整理邮箱、调试代码，AI 正在从"参谋"变成"助手"——能直接产出结果，不再只是出主意。

**结构拆解**：
- 定义（30 字）：一句话讲清楚是什么
- 解释（80 字）：补充背景和内涵
- 例子（50 字）：用 1-2 个生活化场景
- 升华（40 字）：落到行动或感悟

**60 秒演讲模板**：
> "说到 AI Agent，我第一反应是……（举例子）……这告诉我们一个朴素的道理……（升华）今天我想说的是……（个人案例/感悟）"
