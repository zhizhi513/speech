# Type-C 接口

> 标准答案（约 200 字）

Type-C 是新型 USB 接口，特点是可正反插、速度快（USB 3.1/3.2/雷电都支持 Type-C）、能传输视频（DP 替代模式）、能充电（PD 协议）。现在新手机、笔记本基本都是 Type-C。Type-C ≠ USB 3.0——便宜的 Type-C 可能是 USB 2.0 速度。
