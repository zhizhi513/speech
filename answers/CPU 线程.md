# CPU 线程

> 标准答案（约 200 字）

CPU 线程是 CPU 一次能并行处理的指令流。线程分两种：物理线程（核心数）和逻辑线程（通过超线程/同步多线程让一个核心虚拟出两个）。比如 8 核 16 线程，就是 8 个核心能同时跑 16 个任务。线程数决定电脑同时干多少事的极限——浏览器开 100 个标签、视频会议+IDE+微信全开都不卡，前提是线程数够。线程多但 CPU 弱 = 假并行；线程少但 CPU 强 = 真排队。
