# GPU

> 标准答案（约 200 字）

GPU 是图形处理器，最初专为游戏画面渲染设计，现在因为"特别擅长并行计算"被广泛用于 AI 训练、密码挖矿、深度学习。GPU 的特点是：成百上千个小核心同时干重复活，比 CPU 的少量大核心更高效。英伟达（NVIDIA）的 GPU 在 AI 领域一家独大，因为它有 CUDA 编程框架，开发友好。对 AI 工程师来说，GPU 显存大小决定能跑多大的模型；GPU 算力决定训练速度。游戏党关心帧率，AI 党关心显存和 CUDA 核心数。
