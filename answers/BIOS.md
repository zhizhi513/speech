# BIOS

> 标准答案（约 200 字）

BIOS 是主板固件，开机后第一个运行的程序，负责硬件自检、启动操作系统。它是"最底层"的软件——操作系统启动前，BIOS 已经把 CPU、内存、硬盘初始化好了。BIOS 还能让你调硬件设置：CPU 超频、内存频率、启动顺序。早期 BIOS 是文字界面，2020 年后基本升级成 UEFI——图形化界面、支持鼠标。
