# SQL 注入

> 标准答案（约 200 字）

SQL 注入是黑客在网页输入框里塞 SQL 语句，让数据库执行"意外命令"。比如登录框本来该输用户名，黑客输 `' OR '1'='1`，密码框任意，绕过验证直接登录。原理很简单：用户输入被直接拼到 SQL 里执行，没有过滤、没用参数化。黑客能用这个拖走整库、删数据、提权、加后门。防范的"老四样"：参数化查询（预编译）、最小权限、白名单输入校验、ORM 框架。同时配合 WAF、入侵检测、定期渗透测试等多层防御。OWASP 长期把注入列为 Web 第一大风险。它告诉我们：不要相信用户输入；用户输入永远是"潜在敌人"。今天我想说，每一行代码写"防御"，都是给未来自己留的礼物。
