# vibe coding

> 标准答案（约 200 字）

vibe coding 就是"用自然语言让 AI 写代码"的新玩法。这个词由 Andrej Karpathy 2025 年提出，意思是：你不用敲代码，只描述"我想要的感觉"——比如"做一个粉色的、能切换深浅模式的待办 App"——AI 直接吐出完整代码，你只管看效果提修改。它的精髓是用"产品感觉"代替"技术细节"，让产品经理、设计师甚至小学生都能做应用。比如一个博主想给自己网站加留言板，过去找程序员几天，今天 vibe coding 一小时搞定。当然代码可维护性还待提升。它给我们的启示是：AI 让"想法"和"实现"之间的墙塌了，未来最有价值的是"讲清楚你想要什么"的能力。

---

**结构拆解**：
- 定义（30 字）：一句话讲清楚是什么
- 解释（80 字）：补充背景和内涵
- 例子（50 字）：用 1-2 个生活化场景
- 升华（40 字）：落到行动或感悟

**60 秒演讲模板**：
> "说到 vibe coding，我第一反应是……（举例子）……这告诉我们一个朴素的道理……（升华）今天我想说的是……（个人案例/感悟）"
