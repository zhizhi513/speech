# 响应式设计

> 标准答案（约 200 字）

响应式设计是同一个产品能在各种屏幕上都好看能用——手机、平板、电脑、电视、车载屏都要自适应。比如你在电脑上打开一个网页，左边菜单右边上图；换到手机上，自动变成上下叠的布局，按钮变大成手指好按的大小。它的背后是 CSS 媒体查询、弹性布局、流式图片这些技术。但响应式不只是技术，更是设计思维——一个页面要能"优雅降级"，在小屏上不破相、大屏上不空旷。比如微信文章在电脑看是大图大字，手机看自动适配屏幕宽度。今天我想说，做产品早就是多屏时代，只适配一种屏幕，就是丢掉一半用户。
