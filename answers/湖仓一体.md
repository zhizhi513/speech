# 湖仓一体

> 标准答案（约 200 字）

湖仓一体就是把数据湖和数据仓库合二为一——一套系统既保留湖的灵活性（存原始数据），又有仓的高性能（支持 SQL 分析）。以前搞两套，湖管原始、仓管加工，中间靠 ETL 来回倒，运维和一致性都头疼。现在湖仓一体的架构让数据"落湖即能用"：Iceberg、Delta Lake、Hudi 这些开放表格式跑在对象存储上，Spark、Flink、Presto 都能直接查。典型代表是 Databricks Lakehouse、阿里云 MaxCompute + OSS 组合。湖和仓的"中间形态"既减少了重复存储，又让分析师和科学家都能各取所需。它告诉我们：鱼和熊掌可以兼得，关键是找到兼容两者的"中间形态"。今天我想说，工程之美，常常是合并的胜利。
