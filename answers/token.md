# token

> 标准答案（约 200 字）

token 就是大模型"按最小单位计费"的那口粮。AI 不能直接读字，它把文本拆成一小段一小段的"token"——可能是一个字、一个词、半个词，再变成数字喂进去。英文里 1 token 大约 0.7 个单词；中文里 1 个汉字大概 1-1.5 个 token。所以你跟 AI 聊天算费用，看的就是用了多少 token——输入输出都算。比如 ChatGPT 计费页面的"百万 token 多少钱"，就是这个意思。它关乎你两件事：1）省钱——少废话、把任务写紧凑；2）限制——上下文窗口就是"模型一次能读多少 token"，超出就忘掉前面的内容。它给我们的启示是：和 AI 协作也是一门经济学，会精打细算用 token 的人，才能让 AI 用得起、用得稳、用得久。
