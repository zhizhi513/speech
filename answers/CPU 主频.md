# CPU 主频

> 标准答案（约 200 字）

CPU 主频是 CPU 每秒钟执行指令的频率，单位 GHz（十亿次/秒）。比如 3.6 GHz 表示每秒执行 36 亿次基本操作。主频越高，单个任务跑得越快——但只是单核速度。手机 CPU 大约 3 GHz，笔记本 CPU 4-5 GHz，服务器 CPU 3-4 GHz。需要注意：1. 不同代 CPU 不能光比主频；2. 同样的主频，新架构比老架构快；3. 高主频但核心少 vs 多核心但低主频，要看场景。
