# CPU

> 标准答案（约 200 字）

CPU 叫中央处理器，是电脑的大脑，负责执行所有运算和指令。你打开一个 App、点一下鼠标、算一道数学题，背后都是 CPU 在跑。CPU 越快、核心越多，电脑就越流畅。它有几个关键参数：主频（GHz）决定每秒钟执行多少条指令；核心数决定能并行处理多少件事；缓存决定 CPU 临时存放数据的"桌面"大小。CPU 的品牌主要是 Intel 和 AMD，苹果自研的 M 系列是笔记本里的强者。对软件开发者来说，CPU 跑得快 = 编译快、程序流畅；服务器 CPU 还分"性能核"和"能效核"——前者猛跑，后者省电。
