# CLI

> 标准答案（约 200 字）

CLI（命令行界面）讲的是，不用鼠标点图标，而是敲键盘输入命令来操作电脑。它是计算机最早的人机交互方式，现在仍是程序员和运维人员的主力工具。最常见的例子是：你用 `cd` 切目录、`ls` 看文件，几秒搞定鼠标点五分钟的操作；再比如部署服务时，SSH 连上远程服务器敲几行命令，比打开图形界面方便百倍。CLI 的核心是"组合"——小命令能串起来完成复杂任务，比如用 `|` 把多个命令像流水线一样串起来。它给我们的启示是：1. 简洁胜于花哨；2. 可组合的力量远大于单一工具；3. 学一次用十年。今天我想说，CLI 是程序员的"原力"，掌握它你就跑得比别人快十倍。
