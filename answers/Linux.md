# Linux

> 标准答案（约 200 字）

Linux 讲的是，一个 1991 年由芬兰大学生 Linus Torvalds 开源搞起来的操作系统内核，现在统治了服务器、嵌入式、安卓手机。最直观的例子是：你刷的安卓手机底层就是 Linux 内核；你打开淘宝、谷歌、亚马逊，背后几十万台服务器跑的全是 Linux。Linux 的核心是开源、稳定、可定制——任何人都能看代码、改代码、贡献代码。它给我们的启示是：1. 开放能创造奇迹；2. 稳定来自简单；3. 工具可以被所有人塑造。今天我想说，Linux 是程序员送给世界的礼物，免费却比大多数付费软件都强。它告诉我们一个朴素的道理，协作和共享是人类最强的力量。
