# CI/CD

> 标准答案（约 200 字）

CI/CD 讲的是，持续集成（CI）和持续部署（CD）让代码一提交就自动测试、自动上线，告别手工打包。它最早来自极限编程，现在成了现代研发标配。最常见的例子是：你在 GitHub 提了一行代码，CI 系统自动跑测试，全过就发布到测试环境；大厂一天发版几十次，靠人工根本做不到，全靠流水线自动跑完。它的核心是自动化和反馈快——代码出错 5 分钟内就知道，而不是一周才被发现。它给我们的启示是：1. 频繁集成比攒大招更安全；2. 自动化消除低级错误；3. 速度是工程能力的体现。这告诉我们一个朴素的道理，重复的事应该交给机器。今天我想说，CI/CD 是工程师尊严的回归。
