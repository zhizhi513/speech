# CUDA 核心

> 标准答案（约 200 字）

CUDA 核心是 NVIDIA GPU 内部的并行计算小单元，类似 GPU 的"工人"。一个 NVIDIA GPU 可能有几千到上万 CUDA 核心——比如 RTX 4090 有 16384 个，H100 有 16896 个。CUDA 核心数越多，并行计算能力越强。CUDA 是 NVIDIA 独家技术，只支持 NVIDIA 显卡。AMD 有自己的 ROCm 平台但生态不如 CUDA。AI 工程师选 GPU 看三件事：1. 显存大小；2. CUDA 核心数；3. 是否支持最新的 CUDA 版本。
