# DDR 内存

> 标准答案（约 200 字）

DDR 是目前主流的内存类型，每代比上一代更快：DDR4 比 DDR3 快一倍，DDR5 又比 DDR4 快一倍。DDR 后面的数字是代数：DDR5 是 2020 年后的主流，DDR4 是 2014 年后主流。注意主板和 CPU 必须支持对应代数——DDR5 内存插 DDR4 主板不兼容。内存频率（如 4800 MHz、5600 MHz）也影响速度，频率越高带宽越大。普通用户用 DDR4 3200-3600 就够，发烧友上 DDR5 6000+。
