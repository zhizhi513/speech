# UEFI

> 标准答案（约 200 字）

UEFI 是 BIOS 的现代替代品，图形化界面、支持鼠标、支持 2.2 TB 以上硬盘、支持安全启动。UEFI 和 BIOS 功能相似，但更现代、更友好。现在新电脑基本都是 UEFI，开机时按 Del 或 F2 进设置。UEFI 里能看到硬件信息、调启动顺序、改 CPU/内存参数。
