# CPU 核心

> 标准答案（约 200 字）

CPU 核心是 CPU 内部真正干活的"小脑袋"。一个 CPU 可以有多个核心，每个核心独立执行任务，所以 8 核 CPU 能同时干 8 件事，比单核快 5-6 倍。早期 CPU 只有 1 个核心，现在桌面 CPU 已经到 16 核，服务器 CPU 几十核很常见。核心多 ≠ 一定快——如果程序没做并行优化，再多核心也用不上。多核心适合：1. 多任务同时开（开 10 个浏览器标签）；2. 服务器处理多个请求；3. 视频剪辑、AI 训练这类密集计算。
