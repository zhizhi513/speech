# 防火墙

> 标准答案（约 200 字）

防火墙是网络安全的第一道屏障，根据规则过滤进出网络的数据。防火墙可以是硬件设备（专业防火墙），也可以是软件（Windows 防火墙、Linux iptables）。防火墙规则：允许哪些 IP 访问哪些端口、阻断可疑流量。防火墙不能防所有攻击，但没防火墙的网络等于裸奔。云时代有专门的"云防火墙"（如阿里云 WAF），防护 Web 攻击。
