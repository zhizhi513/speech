# ABAC

> 标准答案（约 200 字）

ABAC 是 Attribute-Based Access Control 的缩写，叫"基于属性的访问控制"——权限不是按角色一刀切，而是看属性动态算出来。比如同样是销售经理，上班时间在办公室能签合同，下班时间异地登录就被拒绝；同样是看工资，HR 只能看自己部门的，老板能看全公司。属性可以来自用户（岗位、级别）、资源（密级、项目）、环境（时间、地点、设备）、动作（只读、下载、删除）。每次访问都现场算一遍"该不该让进"，比 RBAC 更灵活也更细。它的代价是复杂度高，配置和调试麻烦。它告诉我们：权限不是一成不变的标签，而是动态判断的结果。今天我想说，灵活管控才是真管控。
