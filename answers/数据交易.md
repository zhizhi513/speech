# 数据交易

> 标准答案（约 200 字）

数据交易是把数据当商品来买卖——一手交钱、一手交数据。打个比方，菜市场卖菜，摊子上摆着标好价的数据集，需求方挑完付款拿走。现在深圳、上海、北京、贵阳都开了数据交易所，里面挂牌"行业洞察""消费者画像""企业信用"等数据产品。交易要解决四个难题：确权（这数据归谁、能不能卖）、定价（怎么算钱）、合规（不能违反 PIPL）、交付（用 API 还是数据包）。常见模式有：原始数据交易（少）、数据服务/报告（多）、API 实时调用（云上场景）。它告诉我们：数据一旦商品化，治理就是"出厂合格证"。今天我想说，交易的不仅是数据，更是信任。
