# DLP 数据防泄漏

> 标准答案（约 200 字）

DLP 是 Data Loss Prevention 的缩写，数据防泄漏系统——专门阻止敏感数据外发的工具。打个比方，公司大门装个安检机，识别身份证、合同这些"贵重物品"，要带走就得审批。常见场景：邮件带敏感词、网盘上传设计图、微信截图、U 盘拷客户名单——DLP 能识别内容、看上下文、自动拦截或告警。技术上靠正则匹配、关键字指纹、机器学习识别敏感数据。常见产品有 Symantec DLP、Microsoft Purview DLP、阿里云 DLP。它是合规的得力助手：PCI-DSS、GDPR、HIPAA 都明确要求。它告诉我们：数据有"出关"流程，才能不裸奔。今天我想说，流程化是反人性的，是反漏洞的。
