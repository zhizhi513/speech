# 显存

> 标准答案（约 200 字）

显存是 GPU 专用的高速内存，类似于 GPU 的"工作台"。显存越大，能同时加载的模型/画面越多——显存不够会直接报错。常见显存大小：游戏卡 8-16 GB，AI 训练卡 24-80 GB（英伟达 A100 80GB 是 AI 训练的香饽饽）。显存和内存的区别：1. 显存带宽更高（GPU 计算需要）；2. 显存和 GPU 直接相连，比内存访问 GPU 快得多；3. 显存比内存贵得多。判断显卡好坏时，显存是核心指标。
